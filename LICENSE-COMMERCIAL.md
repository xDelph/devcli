## FAQ

**Q: Can I use the free version for my business?**
A: You can evaluate it for 32 days. After that, commercial use requires a paid license.

**Q: I'm a solo developer working on client projects. Do I need a license?**
A: Yes, if it's commercial work. You get a 32-day evaluation period, then need to purchase a license.

**Q: Can I try it for free before purchasing?**
A: Yes! 32-day commercial evaluation period. Noncommercial use (personal, education, non-profit) is always free.

**Q: What if I only use it occasionally for work?**
A: Commercial use requires a license regardless of frequency after the 32-day trial. Consider the Individual license ($99/year).

**Q: Do I need a license for every developer?**
A: Yes, each developer using devcli for commercial purposes needs their own license seat.

**Q: Can I use it for my open source project?**
A: Yes! Open source projects are considered noncommercial use and are free.

**Q: My company is a non-profit. Do we need a license?**
A: No. Non-profit organizations can use devcli for free under the PolyForm Noncommercial License.

**Q: What about educational use?**
A: Educational institutions can use devcli for free. No license required.

**Q: What happens when my license expires?**
A: You can continue using the version you have, but won't receive updates or support. Renewal required for updates.

**Q: Can I get a refund?**
A: Yes, 30-day money-back guarantee if not satisfied.

**Q: Do you offer perpetual licenses?**
A: Currently only subscription-based. Contact us for special arrangements.

**Q: What about source code access?**
A: Source code is not provided with commercial licenses. Binaries only.

**Q: Can I redistribute devcli?**
A: No redistribution rights. Each end user needs their own license.

**Q: Enterprise deployment - how does licensing work?**
A: Enterprise license covers all developers in your organization. Contact us for details.
